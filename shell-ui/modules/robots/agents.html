Robots 模块 v1.3.0

Agent 管理中心，从 Dashboard 中独立拆分出来的功能模块。支持 Agent 配置管理、模型测试、状态监控、健康告警、AI 智能修复、工作流追踪、通信拓扑、深浅色主题切换。

架构设计

  • 独立服务 — 纯 Node.js HTTP 服务器，零外部依赖
  • iframe 嵌入 — Dashboard (port 7000) 通过 iframe 加载本模块
  • postMessage 通信 — 跨模块导航通过 window.parent.postMessage

健康监控与 AI 修复

  • auth-state.json — 读取模型调用错误计数和失败时间
  • jobs-state.json — 读取 Cron 任务连续失败次数和诊断信息
  • 健康评分 — 综合认证错误(40%)、响应异常(30%)、活跃度(30%)
  • 告警级别 — healthy(≥80) / warning(≥50) / critical(<50)
  • AI 智能修复 — 调用系统默认大模型生成具体修复步骤

主题系统

  • 深色主题 — 柔和暗色，纯色卡片 + 阴影分层，高可读性
  • 浅色主题 — 暖灰色调，不刺眼，适合白天使用
  • 自动保存 — 主题偏好保存到 localStorage，刷新后保持

工作流面板

  • 会话解析 — 从最新 .jsonl 文件提取 user/assistant/toolCall/toolResult 步骤
  • 子代理追踪 — 识别 dispatchAgent/spawn 调用
  • 实时刷新 — 面板打开时自动 10 秒刷新

通信拓扑

  • 静态配置 — 从 openclaw.json 的 subagents.allowAgents 读取权限
  • 运行时统计 — 从 .jsonl 文件统计 dispatchAgent/spawn 实际调用次数
  • 可视化 — Canvas 绘制有向图，线宽表示调用频率，节点带发光效果

主要 API 端点

GET  /api/agents              # Agent 列表（含健康评分、Cron 状态）
GET  /api/health              # 全局健康概览（含告警列表）
POST /api/ai-fix              # AI 智能修复（调用默认大模型）
GET  /api/agent/:id/workflow  # Agent 工作流步骤
GET  /api/topology            # Agent 通信拓扑（节点+边+调用次数）
GET  /api/models-list         # 可用模型列表
GET  /api/gateway-health      # Gateway 健康检查
PUT  /api/agent/:id/model     # 更新 Agent 模型配置
