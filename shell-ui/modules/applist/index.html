📦 功能概览

AppList 是 OpenClaw 的软件管理面板，用于集中查看、搜索、控制和维护系统中的所有软件服务，提供状态监控、启动控制、自启动管理和一键健康检查。

搜索 刷新 一键检查 自启动

📊 统计卡片

页面顶部提供实时统计卡片，点击卡片可快速筛选对应软件：

  • 托管 — 当前受 AppList 管理的软件总数
  • 运行中 — 处于运行状态的软件数量
  • 已停止 — 已停止运行的软件数量
  • SYSTEMD — 已创建 systemd 服务的软件数量
  • 自启 — 已开启开机自启动的软件数量

📁 软件分类

软件列表按状态分为多个区域：

  • 托管软件 — 已有 config.json 或 systemd 服务，可执行启动、停止、重启、自启动等操作
  • 候选项目 — 工作区内存在目录但缺少配置，可编辑或升级为托管软件
  • 隐藏项目 — 标记为 showInNav: false 的软件，默认折叠
  • 发现的服务 — 通过端口扫描发现的未注册运行中服务

🃏 软件卡片信息

每个软件以卡片形式展示，包含：

  • 名称与描述 — 软件显示名称和简介
  • 状态点 — 绿色表示运行中，灰色表示已停止
  • 类型标签 — systemd / node / python / shell / manual
  • 探测信息 — config.json、package.json、入口文件、.service 等发现标签
  • 元数据 — 端口、状态、启动模式、状态来源、运行路径

⚡ 控制操作

每张托管软件卡片提供以下操作：

  • 启动 / 停止 — 切换软件运行状态，优先使用 systemd
  • 重启 — 一键重启当前软件
  • 自启动 — 开关控制是否随系统开机自动启动
  • 编辑 — 修改软件的 config.json 配置
  • 文档 — 打开该软件的白皮书/说明文档（如果有）

🏷️ 标签说明

  • systemd — 已创建 systemd 服务文件，受系统管理
  • node / python / shell / manual — 按检测到的入口文件类型识别
  • 核心 — 核心服务，关闭自启动受限
  • 外部 — 来自注册表或扫描路径的外部服务
  • 元数据 — 运行目录与配置目录分离，以 runtimePath 为准
  • 发现 — 端口扫描发现的未注册服务
  • 隐藏 — 不在导航中显示
  • 候选 — 尚未托管的候选项目

🔍 一键健康检查

点击顶部「一键检查」按钮，可对所有托管软件执行批量检查，覆盖：

  • systemd 服务文件是否存在且配置正确
  • 自启动状态与预期是否一致
  • 配置文件是否完整

检查结果以弹窗报告形式展示，可切换「全部」或「仅核心」范围。

🖥️ 系统软件

独立的「系统软件」标签页展示系统级服务（非工作区软件），支持查看其运行状态、端口和来源，便于区分用户应用与系统服务。

展示口径：只列出有可执行入口的软件（npm 全局包、pip 带 CLI 的工具、系统命令）。没有 CLI 的包、以及 tqdm/httpx 这类 pip 支撑库属于「库/依赖」，只在统计卡里计数，不进列表——它们是别的软件的零件。

📝 配置文件

托管软件依赖目录下的 config.json，常用字段如下：

{
  "name": "software-id",
  "displayName": "显示名称",
  "description": "软件描述",
  "port": 8080,
  "start": "node server.js",
  "level": "normal",
  "service": "software-id",
  "showInNav": true
}
  • name — 软件唯一标识，通常与目录名一致
  • displayName — 卡片中显示的友好名称
  • description — 软件功能简介
  • port — 服务监听端口，留空表示无端口
  • start — 启动命令，如 node server.js 或 python3 main.py
  • level — normal 普通软件，system 核心服务
  • service — 关联的 systemd 服务名（不含 .service 后缀）
  • showInNav — 是否在导航中显示，false 时进入隐藏项目

高级/可选字段：

  • metadataOnly — true 表示配置目录与运行目录分离
  • runtimePath — 真实运行目录，配合 metadataOnly 使用
  • homepage — 软件主页链接，点击卡片名称可打开
  • category / icon / tags / sort — 分类、图标、标签和排序权重
