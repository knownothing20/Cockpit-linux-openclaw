🛠️ Skill Manager

OpenClaw 技能管理面板

🔍 功能概览

Skill Manager 是 OpenClaw 的技能管理面板，用于查看、筛选、验证和维护所有技能。

总技能 — 扫描到的所有技能总数（含系统内置、扩展插件、工作空间、本地等来源）

有元数据 — 拥有 _meta.json 或 SKILL.md 前区信息的技能数

有依赖 — 声明了外部依赖（dependencies）的技能数

磁盘占用 — 所有技能目录的总大小

🎛️ 筛选与视图

搜索框 — 按技能名称、ID 或描述模糊搜索

分类下拉 — 按技能分类（AI 学习、监控、搜索等）筛选

状态下拉 — 按服务状态筛选（运行中 / 已停止 / 就绪）

来源 Chips — 按技能来源（系统内置、扩展插件、ClawdHub 等）筛选

卡片视图 — 网格卡片展示技能信息（名称、描述、版本、状态、来源）

磁盘视图 — 展示各技能的磁盘占用，含核心文件与 node_modules 占比

依赖视图 — 展示技能之间的依赖关系图

🛠️ 操作按钮

✓ 验证 — 运行 skill-manager.py verify 检查所有技能完整性

🔧 修复 — 运行 skill-manager.py verify --fix 自动修复可修复问题

⬆ 更新检查 — 检查所有技能是否有上游更新，支持 ClawdHub / GitHub / PyPI 来源

📋 刷新注册表 — 运行 skill-manager.py registry 重新生成注册表

✨ 补全元数据 — 运行 skill-manager.py enrich 补全缺失的元数据

📦 技能详情弹窗

点击任意技能卡片可打开详情弹窗，包含：

• 技能基本信息（ID、名称、描述、版本、分类、来源）

• 服务状态（运行中 / 已停止 / 就绪，带颜色圆点标识）

• 磁盘大小与路径

• 使用者（哪些 Agent 配置了此技能）

• 依赖列表

• 操作：检查更新、同步最新、验证此技能、版本号管理

🎨 状态颜色说明

运行中 — MCP 服务正在运行，技能可用

已停止 — MCP 服务已停止

就绪 — 不需要服务的普通技能，随时可用

📡 数据来源说明

系统内置 — OpenClaw npm 包自带的技能（~/.npm-global/lib/node_modules/openclaw/skills）

扩展插件 — OpenClaw 扩展包中的技能（dist/extensions 与用户扩展目录）

工作空间 — Agent 工作空间目录下的技能（workspace-*/skills）

本地 — 用户本地创建的技能（~/.openclaw/custom-skills）

共享技能 — 共享目录下的技能（~/.openclaw/shared-skills）

ClawdHub — 从 ClawdHub 安装的技能

GitHub — 从 GitHub 拉取的技能

PyPI — 从 PyPI 安装的 Python 包技能
